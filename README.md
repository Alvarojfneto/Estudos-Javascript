# Estudos de JavaScript

Repositório criado para registrar minha evolução nos estudos de
JavaScript durante minha formação em Análise e Desenvolvimento
de Sistemas.

Aqui reúno exercícios desenvolvidos acompanhando o curso de
JavaScript do professor Gustavo Guanabara, do Curso em Vídeo,
com práticas e ajustes realizados durante meu aprendizado.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Exercícios

### Hora do Dia

Página que apresenta uma mensagem, uma imagem e uma cor de fundo
de acordo com o horário do computador.

**Conceitos praticados:**

- Obtenção da hora com `Date` e `getHours()`.
- Estruturas condicionais com `if` e `else`.
- Comparações e operadores lógicos.
- Manipulação do DOM.
- Alteração de imagens e estilos com JavaScript.

📁 [Acessar os arquivos](./Exercicio014-HoradoDia/)

### Verificador de Idade

Página que recebe um ano de nascimento e uma opção de sexo,
calcula a idade aproximada pelo ano e apresenta uma imagem
conforme as condições do exercício.

**Conceitos praticados:**

- Leitura de campos de formulário.
- Conversão de valores para números.
- Validação de dados.
- Estruturas condicionais.
- Criação de elementos com `createElement()`.
- Configuração de atributos com `setAttribute()`.
- Inserção de elementos com `appendChild()`.

📁 [Acessar os arquivos](./Exercicio015-VerificadorDeIdade/)

## Como executar

1. Na página do repositório, clique em **Code → Download ZIP**.
2. Extraia o arquivo ZIP.
3. Abra a pasta do exercício desejado.
4. Abra o arquivo com extensão `.html` no navegador.

Mantenha os arquivos HTML, CSS, JavaScript e as imagens
na organização original das pastas.
